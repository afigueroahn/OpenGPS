# Política de seguridad

## Cómo reportar una vulnerabilidad

No abras un issue público para reportar una vulnerabilidad.

Repórtala por el canal privado de GitHub: en la pestaña **Security** del repositorio,
elige **Report a vulnerability**, o entra directamente a
<https://github.com/afigueroahn/OpenGPS/security/advisories/new>.

Incluye, en lo posible:

- La versión o el commit afectado.
- Los pasos para reproducirla.
- El impacto que le ves.

## Versiones con soporte

El proyecto aún no tiene versiones publicadas. Las correcciones de seguridad se aplican
sobre `main`.
