# OpenGPS

OpenGPS es una plataforma de monitoreo en tiempo real, basada en
[Traccar](https://www.traccar.org) y de libre uso.

## Estado del proyecto

En arranque. El repositorio contiene por ahora solo la gobernanza: licencia, guías de
contribución y plantillas. Todavía no hay código de producto ni instrucciones de
instalación.
